# Contract: Day Detail Note UI

## Purpose

Define the user-visible behavior for notes inside day detail.

## Required Behavior

- The user can add a note after opening a day.
- The note is shown again when the same day is reopened.
- The user can edit or replace the note from the same day detail surface.
- A day without a note remains usable and does not require one.
- Notes appear only in day detail.

## Exclusions

- No note display in the month calendar.
- No note preview badges.
- No generated note summary.
- No sentiment labels or coaching text.
